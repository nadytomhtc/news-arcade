# 時事遊樂場：每款遊戲固定規格

新增或修改遊戲時必須沿用 shared/arcade.js、shared/arcade.css。

## 流程
準備 → 開始（使用者操作後啟用音訊）→ 遊玩 → 停止計分 → 結算海報 → 分享／儲存／複製 → 再玩或回大廳。
每局只結算一次；結算後不能繼續計分；再玩清空前局成績與分享檔案。

## 海報
720×900（4:5）PNG，主要內容固定為成績、一句兩行搞笑大標語、角色表情與肢體。成功與失敗用不同配色和角色狀態。下方保留遊戲名、時事遊樂場、網站網址；虛構題材附標示。按鈕不出現在匯出圖內。

## 共用 API
- Arcade.unlock()：只在開始或音效開關的使用者操作中呼叫。
- Arcade.sound('start'|'tap'|'hit'|'tick'|'win'|'lose')。
- Arcade.results.open({canvas,title,score,unit,slogan,gameId,onReplay})：傳入完成繪製的海報。
- Arcade.results.reset()：開始新局時清掉前局分享狀態。

音效簡短、低音量；連打限流避免刺耳；全站記住開關；背景分頁停止音訊。

## 固定分享功能
「海報＋連結」「儲存海報」「複製戰績與連結」「分享到社群」「再玩一次」「其他遊戲」。
原生分享支援檔案才傳 PNG＋文案＋遊戲網址；不支援時提供下載和複製，不把純連結假稱圖片分享。取消分享保留成績。剪貼簿失敗提供可選取文字。手機可長按海報儲存。
Facebook／Threads／X 的網址分享不會自動上傳玩家成績圖；使用者需自行附圖。IG／YouTube 使用手動上傳流程。

## 新遊戲登錄
在 games.js 登錄遊戲與正確 publishedAt，按日期降冪，最新遊戲顯示於主打區與清單首位。

## 驗收
成功／失敗、門檻前後、到時鎖分、重新開始；海報正確與新局重置；原生分享成功／取消／失敗、不支援分享、剪貼簿失敗；靜音與恢復；手機結算可捲動、按鈕可點。

## 時事說明
每款遊戲底部與大廳卡片使用 shared/news.js 提供小問號；區分可查證事實、當事人說法與創作。列出來源與事件日期；虛構題材明確標示，不編造新聞。
