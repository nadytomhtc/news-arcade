# 幫忙拆除舞台恢復交通

第三款遊戲，2026-11-26 上架，取材 2026-11-25 事件。

- 10 個零件，每個零件一顆螺絲。pointerdown 支援觸控滑鼠，click 提供鍵盤操作，停用按鈕防重複計分。
- 開始後以 performance.now 計算真實經過時間；切到背景仍計時，回到分頁或再點時檢查期限。
- 完成門檻（含上限）：10 秒 5 星、20 秒 4 星、30 秒 3 星、45 秒 2 星、60 秒 1 星。逾時或未拆完 0 星。
- 成功後道路車輛通行、角色雙手高舉愛心、煙火動畫；超時為尷尬攤手。減少動態偏好停用循環動畫。
- 共用結算分享：720×900 PNG、星數、時間、已拆數、海報加連結／下載／複製／社群／再玩。
- shared/news.js 為三款遊戲及大廳提供說明；新聞場地說法不等同市府主觀動機已獲證實。
